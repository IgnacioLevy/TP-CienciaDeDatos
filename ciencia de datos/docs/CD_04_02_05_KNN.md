## Página 17

Ventajas:
•
Es de fácil implementación.
•
Es un procedimiento de clasificación simple pero efectivo.
•
Aplica a clasificación multiclase.
•
La frontera de decisión es no lineal.
•
No hay esfuerzo de entrenamiento (aprendizaje perezoso).
•
La calidad de las predicciones mejora con mas datos de entrenamiento.
•
Un único parámetro: K. 
•
Se puede utilizar para regresión.
K Nearest Neigbours (KNN)

## Página 18

Desventajas:
•
¿Que es “cercano”? Se debe especificar una métrica de distancia:
•
Ejemplos: Euclídea, Manhattan, Coseno, etc.
•
El costo computacional: en test, debe almacenar y buscar en el conjunto de
entrenamiento entero. Existen alternativas:
•
Árboles k-d: estructuras de datos mas eficientes que particionan el espacio Euclídeo.
•
Locality Sensitivity Hashing: estructura de datos mas eficiente basada en tablas hash.
•
No tiene un modelo explícito.
•
Si hay muchos datos, el costo computacional sube.
•
La dimensionalidad (m) influye mucho en el rendimiento.
•
Es especialmente problemático ante la “maldición de la dimensionalidad”: mientras 
mas dimensiones se tiene, mas ejemplos se necesitan para aprender la hipótesis. 
•
Al aumentar las dimensiones, decrece exponencialmente el número de ejemplos contenidos en un 
volumen determinado.
Considerar: el porcentaje de observaciones bien clasificadas no es 
monótono en relación a k.
K Nearest Neigbours (KNN)
