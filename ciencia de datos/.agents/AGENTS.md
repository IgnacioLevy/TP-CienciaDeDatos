# Reglas del Espacio de Trabajo

## Consulta Quirúrgica de Documentación (`/docs`)
- Al responder dudas sobre los documentos de la carpeta `docs/`, **NO** leas todos los archivos completos de una sola vez.
- Utiliza primero `grep_search` para encontrar la palabra clave o los capítulos relevantes.
- Lee únicamente el rango de líneas relevante usando `view_file` especificando `StartLine` y `EndLine`.
